# Bandeiras locais

Esta pasta contém as representações PNG das 262 bandeiras usadas pelo aplicativo. Os arquivos são empacotados pelo Metro e não exigem rede durante o jogo.

As imagens são do projeto [Twemoji](https://github.com/jdecked/twemoji), revisão `b6b55fef1e8636b540a6d016a4729ca8cdf2e60b`, e estão licenciadas sob [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Para baixar novamente os arquivos e reconstruir o mapa estático:

```bash
node scripts/download-flag-assets.mjs
```
